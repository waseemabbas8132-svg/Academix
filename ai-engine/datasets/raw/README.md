# Raw handwriting data inventory

Inventory checked on 2026-11-14. Raw files are left untouched and are not
included in version control.

## What is present

- `iam_words/words.txt` uses the IAM word-annotation layout: word ID, status,
  geometry, part-of-speech tag, and transcription. Images are organized below
  `iam_words/words/{writer}/{writer-document}/{word-id}.png`.
- The `iam_words` tree contains about 115,320 PNG files and one annotation file.
  The annotations include both `ok` and `err` statuses. The audit command below
  counts actual valid pairs and detects missing images, malformed rows, corrupt
  images, and duplicate image content.
- `Cursive writing`, `Heavy strokes`, `Irregular spacing`, `Mixed handwriting`,
  and `Neat handwriting` each contain PNG/TXT pairs organized into
  `Extreme`, `High`, `Medium`, and `Low` subfolders. These appear to be writing
  style/quality categories, not train/validation/test splits. Their TXT files
  contain transcriptions.
- No train/validation/test split manifest, Kaggle dataset URL/slug, source
  license, or provenance document was present alongside the raw files when
  inspected. `words_new.txt` is an additional IAM-format annotation export.

## Use and licensing status

The IAM-format data strongly resembles the IAM Handwriting Database, but this
directory does not establish that it came from IAM, identify a Kaggle source,
or include a license grant. The raw dataset is therefore **not used for model
training, tuning, or accuracy claims** until its source and license are
independently verified. The augmented category directories also lack explicit
split assignments and writer IDs, so random image-level splitting would risk
leakage.

Do not delete or rewrite raw files during preparation. The audit utility
creates a writer-disjoint JSONL manifest only after an explicit license
confirmation; exact duplicate and corrupt image records are excluded from that
manifest.

## Audit commands

From `ai-engine`:

```powershell
python -m evaluation.dataset_audit --raw-root datasets/raw --verify-images
```

Only after verifying source provenance and permitted use:

```powershell
python -m evaluation.dataset_audit --raw-root datasets/raw --verify-images `
  --license-confirmed --write-manifest datasets/manifests/iam_words.jsonl
```

The deterministic split is grouped by IAM writer ID (80% train, 10% validation,
10% test buckets); all images by a writer stay in one split. No manifest or
processed dataset is generated by default.
